# Agent LLM 界面重新排版计划

日期：2026-10-12  
状态：设计规划，尚未修改应用代码  
用户选择：均衡密度；各页面整体统一  
设计方向：保留 Windows Fluent 基础，以稳定导航、清楚层级和统一排版提升美感。

## 1. 目标与范围

让模型管理、对话、智能体、向量服务、引擎、API 服务、日志及设置呈现为同一个产品。常用操作位置稳定，信息按重要程度展开，宽窗口充分利用空间，小窗口保留完整操作路径。

本次交付是实施计划。依据当前工作区源代码制定，尚未通过运行中的桌面界面截图验证；文中尺寸属于建议设计值，视觉效果需要在实施阶段校准。现有未提交代码改动作为基线保留。

边界：

- 所有新增界面文案优先中文，技术名配中文主标签。
- 保留现有明暗主题、系统强调色、毛玻璃开关和减少动态效果的支持。
- 保留模型列表视图偏好、排序、搜索、模型选择与记忆参数的现有语义。
- 不修改加载和推理默认值，不改变 `ctx`、`ngl`、KV、batch、parallel、max token、reasoning 的实际行为。
- 自动调参、重置、加载、停止仍由用户显式触发，不因展开页面、切换标签或折叠控件而触发。
- 不增加后端接口，不重写服务生命周期、对话流和数据持久化。
- 不清理编译目录；保留 `app/src-tauri/target/release/` 及最新 exe。

## 3. 推荐的整体布局

采用“固定全局功能栏 + 按需辅助栏 + 页面工作区 + 简洁状态栏”。模型列表直接使用大面积内容区；对话和设置保留各自需要的辅助目录。

```text
┌──────────────────────────────────────────────────────────┐
│ Agent LLM                                    窗口控制 │ 40px
├──────┬────────────┬──────────────────────────────────────┤
│ 对话 │            │ 页面标题                页面操作 │ ≥64px
│ 模型 │ 按需辅助栏 ├──────────────────────────────────────┤
│ 智能体│            │ 搜索 / 页签 / 排序等任务工具栏      │ 按需
│ 向量 │ 对话：会话 ├──────────────────────────────────────┤
│ 引擎 │ 设置：目录 │                                      │
│ 服务 │            │ 主工作区，内容独立滚动              │
│ 日志 │ 其余不占位 │                                      │
│      │            │                                      │
│ 主题 │            ├──────────────────────────────────────┤
│ 设置 │            │ 对话输入 / 参数加载操作，仅对应页面 │ 按需
├──────┴────────────┴──────────────────────────────────────┤
│ 当前服务与后端                 内存 / 显存 / 系统监控 │ 28px
└──────────────────────────────────────────────────────────┘
```

### 3.1 全局功能栏

- 常规宽度 72px，采用现有图标加 12px 中文短标签，入口顺序固定为：对话、模型、智能体、向量、引擎、服务、日志。
- “引擎”对应现有 fast-27b 页面，完整名称在提示中显示；“服务”对应现有 API 服务页，不改路由语义。
- 主题和设置固定在底部。选中状态统一为浅强调色背景、短指示条和同一种图标颜色。
- 800–959px 宽度使用 56px 图标栏，通过悬停和键盘聚焦提示显示完整名称；全部入口仍可达。
- 低高度时导航组单独滚动，底部设置入口仍可见。功能栏保持挂载，页面切换不改变入口位置。
- 不再用模型头像承担全局模式切换。模型家族图标继续承担模型识别功能。

### 3.2 辅助栏

| 场景 | 建议宽度 | 内容与行为 |
|---|---|---|
| 对话 | 224px | 新建、搜索、日期分组会话；导出与删除放在会话操作菜单，保留已有多选能力 |
| 设置 | 192px | 软件设置、核心更新、使用统计、工具、模型主题、数据管理 |
| 模型、API、向量、引擎、日志 | 不设置常驻辅助栏 | 使用页内工具栏、页签或分组，避免空白占位 |

辅助栏折叠是展示状态，不修改模型、后端或请求参数。沿用既有折叠偏好；窄窗口使用抽屉。设置页每次切换仍能从全局功能栏直接进入其他工作区。

### 3.3 页头、内容和状态栏

- 页头基准高 64px，左侧为 20px 标题和必要的上下文，右侧为页面操作；信息过长时允许增高，不固定高度裁掉文字。
- 去掉每页重复的大图标、装饰性英文小标题和功能介绍段落。保留影响操作的说明，例如“修改后需重新加载生效”。
- 工具栏基准高 52px，仅在有搜索、排序或页签时出现；内容不足以容纳时换行，不出现整页横向滚动。
- 主区左右留白通常 24px，窄窗口 16px，分组之间 24px，相关控件之间 8–12px。
- 列表与控制台内容上限 1440px，表单上限 960px，对话消息与输入框共同上限 800px，超宽窗口可到 896px。
- 上限用于控制行长，不把所有页面都压进同一窄列；页头和正文始终共享左侧对齐线。
- 状态栏仅显示当前服务名称、连接状态、端口、内存和显存摘要；细节通过已有系统监控入口查看。
- `ctx` 估算与速度保留在对应对话或服务详情内，避免全局摘要混淆不同模型和引擎。
- 状态栏复用现有采集能力，不因重新排版增加轮询频率；不得把软件内请求计数展示成所有外部请求计数。

## 4. 各页面重新编排

### 4.1 模型管理

从“说明页头 + 密集工具区 + 状态碎片 + 模型项”调整为“模型管理与数量 + 一排工具 + 模型列表”。

- 工具顺序：搜索、排序、列表/网格视图、刷新；外部模型库入口保留为次要操作。
- 模型数量、已加载数量和最近使用数量收为一行摘要。扫描进度或错误放在工具栏下方，避免挤入数量文本。
- 列表模式统一列对齐：模型名称、参数规模/文件大小、量化、能力、运行状态、操作。行高基准 64px；长名称最多两行。
- 网格模式以 260px 为建议最小宽度、16px 间距自适应排布。每项固定信息顺序：家族标识与名称、规模与量化、能力、状态与操作；行内元素预留尺寸。
- 以既有家族图标帮助辨认；背景与边框保持中性，不给每个模型铺不同的大色块。
- “最近使用”采用中性文字与历史图标，错误/警告色只用于真实异常。
- 已加载项保留进入对话，存在记忆参数时保留快速启动。卡片进入参数页、内部操作按钮各自独立响应，键盘行为与鼠标一致。
- 视图切换与排序仅改变展示，不改变既有默认视图和最近使用排序规则。

### 4.2 模型加载与参数

从顶部混排调整为“模型身份 + 参数/信息页签 + 分组表单 + 固定执行区”。

- 顶部保留模型名称、家族图标、量化和必要的显存预测；完整元数据移到已有信息页签。
- 常用参数按“上下文与 GPU 卸载”“KV cache 与运行行为”组织，宽容器两列，窄容器一列；标签、输入值和单位对齐。
- CPU 线程、batch、parallel、RoPE、聊天模板等保留在高级区，沿用现有展开状态，不新增默认参数组合。
- 参数行使用中文主标签，例如“上下文长度（ctx）”“GPU 卸载（ngl）”；数值输入、滑块与步进沿用当前值域及转换逻辑。
- 将运行记录和自动调参过程组织为可展开区域，保留当前用户触发后的应用结果行为。
- 底部操作区基准高 56px，始终可见：自动调参、重置为次要操作，加载/重新加载为主要操作；运行期间保留当前可用的停止入口。
- 加载进度和错误在操作区上方自然占位，长日志可展开，不用浮层盖住正在编辑的参数。
- 固定操作区通过布局行占位，不采用盖在表单上的绝对定位；不能同时出现两个加载主按钮。

### 4.3 对话

采用“全局功能栏 + 会话栏 + 对话正文”，保持对话阅读区安静。

- 页头保留会话标题、当前模型/后端和必要连接状态；历史会话模型与当前运行模型明确区分。
- 后端选择仍是显式操作，不因切换会话、页面或视觉标签而更改。
- 会话列表行高基准 40px，新建与搜索固定在上方，多选工具只在对应状态占位。
- 助手回复使用无框正文，用户消息保留轻背景；代码块使用等宽字体，长表格与代码仅在自身区域横向滚动。
- 消息区与输入区共同使用 `minmax(0, 1fr) auto` 的布局：消息独立滚动，附件、错误和输入框自然占位。
- 保留输入框当前自动增高上限 168px；附件超过可用高度时在附件区域内部滚动，避免挤掉消息区。
- 上传、思考强度、工具选择、发送/停止保持同一操作序列；窄窗口可分两行，当前有效的思考挡位仍清楚可见。
- 对话参数仍使用右侧面板/抽屉，正文空间不足时覆盖展示；关闭后焦点回到触发按钮。
- 思考菜单与工具菜单使用不会被输入框边界裁切的浮层；动态输入高度同步更新虚拟列表的可用高度和到底部按钮位置。
- 保留当前输入框以边框变化提示聚焦的方式，不新增大面积蓝色发光效果。

### 4.4 API 服务

调整为“紧凑服务摘要 + 连接信息 + 运行数据 + 高级设置”。

- 第一屏优先显示服务状态、当前模型、Base URL、鉴权状态和立即检测。
- 连接信息使用对齐的键值行与复制图标；API key 的隐藏和管理行为沿用现有实现。
- 移除同心圆装饰，缩小展示式标题，不用大面积卡片重复说明“运行中”。
- Token、请求次数和实时速度采用一组等宽数据列，数字等宽对齐，单位紧随数值。
- 软件内对话与对外 API 统计继续明确区分；fast-27b 不暴露的数据展示“不可获取”，不填造数值。
- 访问范围、端口、API key 和调用示例保留在高级设置中；“修改后需重新加载生效”的提示继续可见。
- 常规分区采用标题、间距和分隔线；复制字段与调用示例可以使用有边界的工具区域。

### 4.5 智能体、向量服务与引擎

- 智能体：统一页头，在页头下保留 dsh / 官方 WebUI 页签；子面板不再重复占用一整套页头，安装、启动及外部入口位置一致。
- 向量服务：按“模型选择 → 运行参数 → 启停与状态 → 调用信息”编排；Embedding 与 Rerank 的能力和运行状态分别标明，不混入主对话模型状态。
- fast-27b：按“引擎与模型选择 → 运行状态 → 启停 → 配置与日志”编排；复用现有选择和启停逻辑。
- 三类页面统一使用分区表单和状态行，移除将整个章节包进浮动卡片的布局；已有日志区作为真正的工具区域保留边界。
- 当容量允许时采用主区加右侧运行摘要，主区不足 1000px 时改为上下排列，摘要不挤压参数输入。

### 4.6 设置、更新、统计和数据管理

- 保留设置中心现有六类目录与页面，不增加新的顶层功能。
- 软件设置按外观、本地模型运行、网络代理、窗口与托盘分组；标签在左、控件在右，说明放在标签下方。
- 目录选择、路径、代理地址和保存按钮在窄窗口上下排列；路径可复制或查看完整内容，避免只剩省略号。
- 核心更新沿用相同的表单宽度与页头规范，版本信息、下载进度和操作形成稳定的顺序。
- 使用统计保留现有图表与统计口径，筛选在工具栏，关键数值优先，图表在同一栅格中对齐。
- 模型主题保留实际家族图标和色板；色彩使用色块选择，避免用文字按钮代替色板。
- 数据导入、导出和清理分组排列，破坏性操作保留现有确认机制，视觉上与常规按钮区分。

### 4.7 日志

- 页头、实时刷新开关、复制、导出、清空占据固定上方区域，日志正文使用剩余高度。
- 行数与刷新状态用文字表达，减少胶囊标签；去掉仿其他平台窗口的红黄绿装饰点。
- 正文保留原始日志和等宽字体，异常行增加语义色与标记，不改日志内容。
- 暂停后阅读位置稳定；恢复、跳到底部沿用当前行为。长日志在正文内换行；如保留横向滚动，局限于日志正文，不让整个页面横向移动。

## 5. 视觉规范

### 5.1 字体、间距与形状

| 项目 | 建议规范 |
|---|---|
| 默认字体配对 | 界面 Segoe UI Variable / Microsoft YaHei UI；代码 Cascadia Mono / Consolas，复用现有字体栈 |
| 可选配对 | 思源黑体 + JetBrains Mono；Noto Sans SC + Cascadia Mono。仅作为后续方向，本轮不下载或打包字体 |
| 字号 | 辅助 12px、正文 14px、对话 15px、分组标题 16px、页标题 20px、关键数值 22px |
| 字重与字距 | 正文 400、标签 500、标题 600；中文界面字距统一为 0，取消展示式负字距与标签大字距 |
| 行高 | 界面 1.5、对话长段落沿用现有 1.78、代码沿用 1.6 |
| 间距刻度 | 4 / 8 / 12 / 16 / 24 / 32px；页面 24px、章节 24px、相关控件 8–12px |

| 分隔与阴影 | 区域使用 1px 中性分隔线；仅菜单、抽屉和弹窗保留层次阴影 |
| 动效 | 聚焦和悬停约 120ms、抽屉约 180ms；取消逐卡依次入场和装饰性持续动画，服从减少动态效果设置 |

现有圆角变量统一时逐组件迁移，不能直接全局替换，避免同时影响对话气泡、弹窗和不在本轮首批范围内的组件。

### 5.2 色彩

以现有中性灰、系统强调色和语义色为基础，颜色用于识别操作与状态，主要布局依靠对齐和间距。

| 语义变量 | 浅色建议 | 深色建议 | 用法 |
|---|---|---|---|
| `--app-bg` | `#FAFAFA` | `#1B1B1B` | 工作区背景 |
| `--surface` | `#FFFFFF` | `#262626` | 输入、菜单与真正有边界的工具 |
| `--surface-muted` | `#F3F3F3` | `#303030` | 导航与辅助区 |
| `--text-primary` | `#1C1C1C` | `#F5F5F5` | 正文、标题与数值 |
| `--text-secondary` | `#5D5D5D` | `#D4D4D4` | 标签与必要说明 |
| `--text-tertiary` | `#707070` | `#B0B0B0` | 次要注释；不承载唯一错误或运行状态 |
| `--accent` | 系统色，默认 `#0078D4` | 系统色，默认 `#4CC2FF` | 主操作、选中和链接 |
| 成功 / 警告 / 错误 | 沿用现有语义色 | 沿用现有语义色 | 状态同时附带文字或图标 |

强调色背景上的文字使用可读的前景变量，不统一写死白色。主题色自定义、毛玻璃透底和禁用态均需要对照真实背景检查；正常正文对比度验收目标不低于 4.5:1。取消主工作区的装饰点阵与指针吸附效果，保留真实模型标识作为视觉识别素材。

### 5.3 组件状态与可访问性

- 按钮统一包含默认、悬停、按下、聚焦、禁用、处理中状态；忙碌图标预留宽度，按钮文案变化不挤动邻项。
- 图标按钮有中文可访问名称和悬停/聚焦提示；主要操作不依赖悬停才出现。
- 输入控件保留显著聚焦边界，键盘操作有可见焦点；不使用移除全部反馈的 `outline-none` 组合。
- 页签使用匹配的 `tablist`、`tab`、`tabpanel` 语义及方向键切换；导航使用当前页标记。
- 抽屉和弹窗处理焦点进入、焦点约束、Esc 关闭和关闭后焦点恢复。
- 空列表保留当前区域标题和一个可执行的下一步；搜索无结果与尚未扫描模型分别表达。
- 加载状态保留内容骨架或稳定占位；模型服务加载沿用真实进度，不用假进度替代。
- 错误在对应区域内展示中文解释和已有的重试/日志入口，原始错误可展开；错误内容不挤进全局状态栏后被截断。
- 数据未知、不可获取、未连接与数值为零分别表示，不把未知值写成 0。

## 6. 窗口适配与滚动

当前桌面配置为初始 1200×780、最小 800×600。此次不修改窗口尺寸约束，所有布局尺寸按 WebView 内的 CSS 像素计算。

| 可用宽度 | 布局策略 |
|---|---|
| ≥1440px | 完整功能栏，辅助栏按需展开；列表与控制台最多 1440px，保持文字行长 |
| 1100–1439px | 常规双栏表单；对话会话栏可展开，参数面板按剩余空间选择抽屉 |
| 960–1099px | 按容器宽度决定单双栏，优先保证主工作区；辅助栏可折叠，不缩小正文字号 |
| 800–959px | 56px 功能栏，辅助栏变抽屉，表单一列，工具栏允许两行 |

断点是初始建议，表单列数和工具栏重排优先使用内容容器宽度，不能只依据窗口宽度。低高度优先压缩非必要留白，主工作区、会话列表和日志正文各自滚动；避免整个页面与内部表单同时出现纵向滚动条。

## 8. 验收标准

视觉与布局：

- 在 1200×780 默认窗口、800×600 最小窗口、1366×768、1600×900、1920×1080 下检查主要页面。
- 检查 Windows 100%、125%、150% 缩放；使用实际 WebView 内容宽度判断断点，不用缩小字体补救溢出。
- 浅色、深色及毛玻璃开/关均检查标题、正文、焦点和危险操作的可读性。
- 同类页头、工具栏、表单、按钮和分隔线使用同一规范；无意外页面横向滚动、文字重叠、浮层裁切。
- 对话检查长中文、长模型名、代码、表格、多附件、流式输出、展开思考、停止、跳到底部和历史会话。
- 参数页滚动到底部仍能加载/停止；错误长文本和运行日志不遮挡输入控件。
- 菜单、抽屉、弹窗和导航可用键盘完成操作，焦点顺序可预测。

行为与性能：

- 改造前后对比相同模型、相同配置生成的启动参数和请求 JSON；所有加载与推理参数值、自动挡语义、参数省略规则一致。
- 扫描、快速启动、记忆参数、加载、重置、自动调参和停止继续按原有显式操作触发。
- 页面切换不得新增服务重启、对话中断、会话错误归属、草稿丢失或多套重复轮询。
- 保留 API key 管理、外部访问设置、统计口径、日志复制导出和数据管理确认机制。
- 运行 `npm run lint`、`npm run build`，区分已有问题与本轮引入问题；针对布局和流式对话运行必要的浏览器交互检查。
- 浏览器负责展示与交互验证；真实模型加载、系统强调色、毛玻璃、窗口拖动和托盘必须在 Tauri 桌面环境复核。
- 需要 exe 交付时运行 `npm run desktop:build`，核对产物位于 `app/src-tauri/target/release/agent-llm.exe`。本次规划阶段不执行构建、不替换 exe。
