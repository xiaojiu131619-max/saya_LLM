## 修复原则

## 已修复（6 项）

### 1. 142 处字号令牌失效（P0，影响面最大）

- **问题**：`text-[var(--font-*)]` 被 Tailwind 解析为 **color** 工具类，字号声明根本不生成，文字回落到继承的 14px。
- **改法**：加类型提示 `text-[var(--font-*)]` → `text-[length:var(--font-*)]`。
- **文件**（6 个，共 142 处）：

  | 文件 | 处数 |
  | --- | --- |
  | `app/src/pages/ChatPage.tsx` | 46 |
  | `app/src/features/apiStatus/ApiStatusPage.tsx` | 36 |
  | `app/src/features/chat/ChatSidebar.tsx` | 17 |
  | `app/src/components/ChatBubble.tsx` | 16 |
  | `app/src/features/apiStatus/ExternalApiSection.tsx` | 14 |
  | `app/src/components/MarkdownRenderer.tsx` | 13 |

- **验证**：生产 CSS 产物中 7 个令牌（body/caption/chat/display/eyebrow/subtitle/title）全部生成 `font-size`；残留 `color:var(--font-*)` **0 处**。
- **副作用**：无。文字颜色不受影响（`--font-*` 那条无效声明输给了同元素的真实颜色类）。

### 2. `.page-title` 从未定义（P0）

- **问题**：`PageHeader.tsx:21` 的 h1 引用 `.page-title`，该选择器全仓库 0 处定义 → 主标题无任何规则，实测 14px/400。
- **改法**：在 `app/src/index.css` 的 `@layer components` 补定义：

  ```css
  .page-title {
    font-size: var(--font-title);   /* 18px */
    font-weight: 600;
    line-height: var(--leading-tight);
    letter-spacing: var(--tracking-tight);
    color: var(--text-primary);
  }
  ```

- **影响面**：11 个使用 `PageHeader` 的页面。
- **验证**：11 个页面 h1 实测全部为 **18px / 600**，层级变为 18/600（页面主标题）> 15/600（区块标题）> 14（正文）。

### 3. `--font-page` 令牌不存在（P0）

- **问题**：`app/src/workspace-design.css:7` 用 `font-size: var(--font-page)`，该令牌 0 处定义 → 整条声明作废，模型库页标题从 JSX 里写的 20px/700 塌到 14px。
- **改法**：改用已定义的 `--font-title`，与 `.page-title` 同档。
- **验证**：模型库页 h1「模型管理」14px/600 → **18px / 600**。

### 4. `h-4.5 / w-4.5` 不生成 CSS（P0）

- **问题**：Tailwind v3 默认 spacing 刻度有 `3.5` 但没有 `4.5`，`tailwind.config.js` 也未扩展 → 该类不生成任何 CSS，lucide 图标回落到默认 **24×24px**，比它旁边的 15px 区块标题还大。
- **改法**：`app/tailwind.config.js` 扩展 `spacing: { 4.5: '1.125rem' }`。
- **验证**：区块图标 24×24 → **18×18**；产物 CSS 含 `.h-4\.5{height:1.125rem}`。
- **影响面**：`SettingSection.tsx:27`、`McpServersSection.tsx:230`、`ToolsPage.tsx:53/96/137`、`LogsPage.tsx:19`。

### 5. 连带修复：对话页页头溢出（第 1 项改出来的问题，必须一并修）

- **问题**：字号生效后，页头三行（11px + 18px + 12px）实测占 61px，而该行固定 60px → `scrollHeight 61 > clientHeight 59`，上下各溢出约 2px。
- **改法**：`ChatPage.tsx:1544` 的 `grid-rows-[60px_minmax(0,1fr)]` → `grid-rows-[72px_minmax(0,1fr)]`，给三行文字上下各留约 8px 余量。
- **验证**：行高 72px、`clientHeight 71 = scrollHeight 71`、`overflow=false`。

### 6. 计数「00」与空态文案/按钮名不一致

- **计数**：`HomePage.tsx:135` 的 `padStart(2, '0')` 在 0 个模型时渲染成「00」，空状态下像未初始化的占位符 → 改为直接显示真实数量，实测由「00」变为「0」。
- **文案**：`HomePage.tsx:289` 原文「或点击上方「下载」面板在线拉取模型」，而实际按钮叫「魔搭下载」且行为是 `openExternalUrl`（跳外部浏览器）→ 改为「或点击上方「魔搭下载」在浏览器中打开魔搭模型库」，使按钮名、说明、行为三者一致。
